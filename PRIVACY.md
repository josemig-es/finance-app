# Privacy Notice — Finance App

Finance App is a personal, non-commercial project used only by its owner.

- It reads the owner's own bank data through Enable Banking (PSD2), with the owner's explicit consent.
- All data is stored **locally** on the owner's computer, in a SQLite file. It is never sent to third parties, sold or shared.
- No other users exist; no personal data of other people is collected.
- The owner can revoke the bank access at any time from the bank or Enable Banking, and delete the local data by deleting the database file.

Contact: see the repository owner on GitHub.
